# Security Policy

## Supported Versions

This is a personal learning project without formal releases — only the
latest `main` branch is maintained.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you find a security issue in this project, please open a
[GitHub Issue](https://github.com/soerenlemke/kvstore_c/issues) or use
GitHub's private vulnerability reporting (Security tab → "Report a
vulnerability") if you'd rather not disclose it publicly first.

This is a hobby project I maintain in my spare time, so there's no
guaranteed response time — but I'll take a look as soon as I can and
let you know whether it's something I can fix.
